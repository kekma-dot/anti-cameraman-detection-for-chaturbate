# Anti Operator Detection for Chaturbate

**Русский** · [English](README.en.md)

![Карикатурный оператор с молотком разбирается с логотипом Chaturbate](assets/operator-vs-typing.png)

Когда работаешь в чате, а три точки уже сдали всю контору.

«Никто не узнает, что вместо тебя общается твой парень».

Расширение для Chrome, которое блокирует исходящий сигнал «печатает…» в личных сообщениях Chaturbate.

Название громкое, функция конкретная: убрать индикатор набора. Расширение не скрывает, кто сидит за клавиатурой, и не гарантирует, что оператора невозможно распознать другими способами.

## Установка

1. Скачай [ZIP с кодом](https://github.com/kekma-dot/anti-operator-detection-for-chaturbate/archive/refs/heads/main.zip) и распакуй.
2. В том профиле Chrome, где открыт аккаунт модели, зайди на `chrome://extensions/`.
3. Включи «Режим разработчика» и нажми «Загрузить распакованное расширение».
4. Выбери папку **`extension`** внутри скачанного проекта. Не корень проекта и не ZIP.

Отдельной кнопки у расширения нет. Пока оно включено в Chrome, правило активно. Чтобы вернуть индикатор, выключи расширение на той же странице.

## По чему бьёт молоток

По одному запросу:

```text
POST https://chaturbate.com/api/messaging/typing/
```

Правило учитывает query-параметры и срабатывает на `fetch`/XHR. Отправка сообщения идёт на другой адрес, `/api/messaging/publish/`, который правило не блокирует.

Внутри только Manifest V3 и статическое правило Chrome `declarativeNetRequest`. Исполняемых скриптов в расширении нет. Оно не читает сообщения, не получает cookies и не отправляет переписку на сторонний сервер. Единственное разрешение: `declarativeNetRequest`.

## Где молоток бессилен

- Блокировка действует для всех получателей в установленном профиле. Общий адрес используется PM/DM; выбрать один диалог нельзя.
- Правило привязано к точному адресу на `chaturbate.com`. Другие домены, пути и способы отправки сигнала оно не покрывает.
- Если сайт поменяет механизм индикатора, потребуется обновить расширение. Гарантии «поставил и навсегда невидим» здесь нет.
- Сайт может показывать сетевую ошибку для заблокированного запроса. Расширение не подделывает успешный ответ.

Для проверки нужны два аккаунта: на одном набираешь текст, на другом смотришь, исчез ли индикатор. Затем проверь доставку обычного сообщения. Не отправляй случайно старый черновик, пока воюешь с тремя точками.

## Проверки

Прототип `0.1.0`: 18 случаев проверены в Node и через настоящий движок правил Chromium 153. Проверяются разрешения, точное совпадение адреса и исключения для отправки сообщений и других запросов. Полный двухаккаунтный A/B-тест с проверкой доставки пока не зафиксирован в результатах проекта.

Быстрая проверка без зависимостей:

```sh
node tests/check.mjs
```

Дополнительная проверка в Chromium использует уже установленный Playwright и отдельный временный профиль:

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
CHROMIUM_EXECUTABLE=/absolute/path/to/chromium \
node tests/chrome.mjs
```

`CHROMIUM_EXECUTABLE` можно не задавать, если браузер, который ожидает твой Playwright, уже установлен. Временное вспомогательное расширение для теста не входит в папку `extension` и не нужно для обычного использования.
